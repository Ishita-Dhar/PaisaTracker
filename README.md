
# PaisaTracker

PaisaTracker is a personal finance management web application that I am building to make it easier to keep track of income, expenses, and everyday spending.

The main goal of this project is to create a simple and clean interface where users can manage their finances and understand their spending habits.

## Project Status

This project is currently in development. I am working on the frontend and gradually adding new features and improving the existing ones.

## Features

Currently, the project includes:

- Dashboard for viewing financial information
- Income and expense tracking UI
- Transaction search and filtering
- Settings page
- Edit profile functionality
- Dark mode (in progress)
- Responsive design

More features will be added as development continues.

## Tech Stack

The project is currently built using:

- React.js
- JavaScript
- Tailwind CSS
- shadcn/ui
- React Icons
- Vite

## Getting Started

To run the project locally:


### 1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Open the project folder
cd PaisaTracker

### 3. Install the dependencies
npm install

### 4. Start the development server
npm run dev

The application will then be available at:

http://localhost:5173
